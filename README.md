mohib080/Database# 📚 Libri – Full-Stack Online Bookstore

**Libri** is a full-featured database project built with PostgreSQL, Node.js, and a responsive HTML/CSS/JavaScript frontend. It offers a seamless platform for users to browse and order books, for sellers to manage inventory, and for admins to monitor the system — all in one place.

---

## 🚀 Features

### 👤 User Features
- Signup & Login
- Browse recommended books
- Filter by category and subcategory
- Search by book name or author
- View detailed book pages
- Add, update, and delete reviews and ratings
- Add books to wishlist and cart
- Place orders for different formats (eBook, hardcover, paperback)
- Enter shipping and payment info
- Cancel orders while pending
- can reorder the item after delivery
- Track order status (pending → processing → shipped → delivered)
- Download PDF receipt after delivery
- Live chat with admin

### 🛠️ Admin Features
- Admin-only login
- View all customers and sellers
- Receive notifications: new orders, reviews, low stock alerts
- Admin dashboard with website-wide stats
- Track and update order statuses
- Chat with users via live chat

### 🧑‍💼 Seller Features
- signup & login
- Add books (with multiple formats) to inventory
- View order/delivery/revenue stats for supplied books
- Receive notifications for new reviews and low stock
